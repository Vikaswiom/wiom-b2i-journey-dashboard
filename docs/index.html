Definitions, data sources and caveats
  • Task: one booking sent to one CSP as a Booking FPN, the TAS install execution candidate. When a CSP declines or ignores an FPN, the booking goes to another CSP as a new task. So the task-level install share is lower than the booking-level one.
  • Cohort: every install task created — to — (IST): a 13-day window ending 5 days before the last update, so every task has had time to finish. It moves forward with each refresh. Since 3 Nov every task goes through the CSP-acceptance flow. Outcomes are counted up to the snapshot time, at least 3.5 days after the last task. Under 1% of tasks were still open.
  • Backend steps come from CSP_TAS_SERVICE.INSTALL_STATE_TRANSITION_LOG, the first time each task reached the state. FPN steps come from CSP app events in CLEVERTAP_CSP_API.EVENTS_DATA, joined on execution_id: install_task_created (push sent), fpn_delivered (full-page popup drawn on the phone), fpn_action_taken (tap or dismiss) and install_candidate_opened.
  • No response: the task left AWAITING_CSP_ACCEPTANCE with reason TIMEOUT_P41. Timed out, task not moved: reason CSP_NO_SHOW after the CSP had accepted.
  • Installed: the technician submitted the customer's happy code (OTP) and it was verified (AWAITING_CUSTOMER_OTP → RATING_PENDING). That is when the customer's internet goes live. The customer rating that follows is not needed to count as installed.
  • “Other (free text)” is the largest failure reason after acceptance. Those notes are not yet categorised.
  • This is a fixed snapshot from Snowflake through Metabase. Each source in Sources holds the exact SQL.

How this page is worked out
  • Window: installs from — to — (the 30 days up to yesterday, IST), by the CSP that did the install.
  • Late, never rescheduled: installed after the slot day with no CSP reschedule on that task before the install.
  • Used reschedule: any ES_INSTALL_SLOT_AUTO_REDATED with source CSP_RESCHEDULE on the CSP's tasks since 18 Sep 2026. The app sends no event when a CSP opens the reschedule option, so a CSP who looked at it but didn't use it counts as never used.
  • App version: the latest CSP app version seen on the owner's or manager's phone in the last 10 days. Blank = no app activity from them in that time.
